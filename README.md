# TrialTrack

Demo clinical trial registry. Fake data only. Not for real patient or medical use.

## Stack
- Web: Next.js (App Router), React, TypeScript, Vercel
- API: Django (REST + GraphQL), Render
- DB: Postgres (Supabase), kept awake via UptimeRobot
